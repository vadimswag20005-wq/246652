# Учёт оплаты обучения студентами

Веб-приложение для управления учётом оплаты обучения студентами.

## Возможности

- ✅ Добавление и редактирование информации о студентах
- ✅ Управление платежами студентов
- ✅ Отслеживание статуса оплаты (оплачено полностью, частично, не оплачено)
- ✅ Визуализация прогресса оплаты с помощью прогресс-бара
- ✅ История всех платежей
- ✅ Статистика по всем студентам
- ✅ Поиск студентов
- ✅ Автоматическое сохранение данных в браузере (localStorage)

## Использование

1. Откройте файл `index.html` в любом современном браузере
2. Нажмите "➕ Добавить студента" для добавления нового студента
3. Заполните информацию о студенте:
   - ФИО
   - Группа
   - Телефон (необязательно)
   - Email (необязательно)
   - Стоимость обучения
4. Для добавления платежа нажмите "💳 Платежи" на карточке студента
5. Используйте поиск для быстрого нахождения студентов

## Особенности

- Все данные сохраняются автоматически в браузере
- Адаптивный дизайн для работы на разных устройствах
- Современный и интуитивный интерфейс
- Цветовая индикация статуса оплаты

## Технологии

- HTML5
- CSS3 (с градиентами и анимациями)
- Vanilla JavaScript
- LocalStorage для хранения данных
